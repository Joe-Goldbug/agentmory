## 测试策略

### 单元测试
- 后端: Jest + Supertest
- 前端: Jest + React Testing Library
- 覆盖率: ≥ 80%

### 集成测试
- API 端点测试
- 数据库交互测试
- 第三方服务集成测试

### E2E 测试
- 关键用户流程
- 错误场景
- 边界情况

### 性能测试
- 响应时间: < 200ms
- 吞吐量: > 1000 req/s
- 内存使用: < 500MB
