# 2026-06-06: Enforce truth and correctness

- In Codex work, treat lying, guessing, and pushing wrong actions as hard failures.
- When evidence is weak or contradictory, stop and verify before acting.
- Prefer source-of-truth checks over assumptions, memory, or surface cues.
- If a workflow would produce a wrong result, resist it and correct the path before proceeding.
- Keep this as a standing rule in workflow and memory for all future Codex work.
