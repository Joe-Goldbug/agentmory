# 全局统一工作流 (Master Workflow)

> **版本**: v2.2-结论型
> **最后更新**: 2026-04-21

## 模块: EPEV 循环（核心工作流）

**先探索，后动手，大改先确认。**

1. **探索 (Explore)** → 绝不盲目写代码
   - 用 Glob/Grep 定位，不读整文件
   - 大文件用 offset/limit
2. **计划 (Plan)** → 2+文件修改必须先出计划
   - 拒绝预防性重构
3. **执行 (Execute)** → 小步快跑，一次只做一件事
4. **验证 (Verify)** → 改后必测，禁止未测就 push

## 模块: 角色化思考

**接收到对应意图，立即切换角色。**

| 触发词 | 角色 | 核心行为 |

## 模块: 上下文清理

**上下文贵且乱，条件到即清。**

- 清空 (Clear/New Chat)：任务验收完成 / 切换完全不同主题
- 压缩 (/compact)：Token >150K / 大阶段完成

---

## 模块: Token 优化

**三次节省：Diff-Only、切片、摘要。**

| 规则 | 操作 |
|------|------|
| Diff-Only | Edit 只传 old→new，不传整段，不用 Write |
| 函数切片 | Grep -n → Read ±10行，不读整个文件 |
| 上下文摘要 | 长任务用"已完成/当前问题/下一步"替代历史 |
| 去重 | 同一报错只解释一次，后续引用 |
| 验证命令 | curl/psql/build，不 Read 文件 |

## 模块: ethanmini 指令原则（绝对优先级）

**5条高压线，违反即停手先问。**

| 原则 | 含义 | 违反反应 |
|------|------|---------|
| 不确定的先问 | 模糊需求，先问清楚再动 | 停止→提问→等待 |
| 别瞎猜代码 | 不确定行为，先验证再改 | 停止→查文档→确认后动 |
| 能简短就别写长 | 简洁优先，只说结论 | 不写过程 |
| 没让改的地方别碰 | 严格按范围，超出即报 | 停手并报告 |
| 给目标别给步骤 | 接受目标导向 | 我推导步骤 |
