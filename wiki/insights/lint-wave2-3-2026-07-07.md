## What changed (delta over wave 1)

| Gap | 来源 | 改动位置 | 性质 |
|-----|------|---------|------|
| 2 Recurrent Block | Looped World Model 的 shared transformer loop | `lwm/query.py` `run_query()` | K 轮渐进收紧 K，每轮加新信号 |
| 4 Stability ρ(Ā)<1 | Looped World Model 的 spectral-stable transitions | `lwm/analysis.py` + `lwm/query.py` | WikiPage 加 `updated` / `last_used_at` / `use_count` 字段；_score_page 加衰减因子 |

**关键设计：Wave 2 依赖 Wave 3 的信号**
- K 轮精炼需要"新信号"才有意义
- 纯 latent 排序反复跑 = 空转
- Wave 3 的 `use_count` / `last_used_at` 是新信号源
- 所以 K 轮精炼 = latent → latent+stability → latent+stability+body
- 3 轮 = 3 个信号层级

### 具体改动

**Wave 3 (Stability 衰减) — 5 处**

1. `lwm/analysis.py` — 加 `_parse_int(value)` 辅助函数（frontmatter int 容错解析）
2. `lwm/analysis.py` — `WikiPage` 加 3 个字段：`updated: str = ""`, `last_used_at: str = ""`, `use_count: int = 0`
3. `lwm/analysis.py` — `collect_wiki_pages()` 读这 3 个字段
4. `lwm/query.py` — 加常量 `_DECAY_LAMBDA = 0.99`
5. `lwm/query.py` — 加 `_stability_factor(page)` 函数（age_decay × use_boost）+ `_apply_stability(score, page)`
6. `lwm/query.py` — `_score_page` 末尾应用 stability：`score = round(_apply_stability(score, page))`

**Wave 2 (Recurrent Block) — 1 处**

7. `lwm/query.py` — `run_query()` 改 3 阶段 K 轮收紧：
   - Round 1: latent 排序，K1 = max(limit * 16, 100)
   - Round 2: latent + stability rerank，K2 = K1 // 2
   - Round 3: latent + stability + body（materialize），K3 = max(limit * 8, 50)

### 字段设计原则

- **`updated` 字段**：之前 frontmatter 里有但 WikiPage 没读（这是 wave 2 测试发现的 bug——`page.updated` 触发 AttributeError），顺手补上
- **`last_used_at` / `use_count` 字段**：可选，缺则 fallback 到 0 / ""（老 wiki 不需 migration）
- 衰减参数 `λ = 0.99`：每天衰减 1%，半年后剩 16%
- `use_boost = 1 + log(1 + use_count)`：log 曲线，bounded

## 决策记录

- **不强制老 wiki migration**：`last_used_at` / `use_count` / `updated` 字段都
  给了 fallback（空字符串/0），老 wiki 不需任何改动
- **schema REQUIRED_KEYS 不改**：避免破坏现有 wiki 验证
- **衰减参数 λ=0.99**：偏温和（半年剩 16%），适合个人知识库的"温和淘汰"
- **K 轮 K 收紧比例 16→8→final**：从宽松到严格，留出 rerank buffer
- **不动 `quick` mode body 读取**：原 `_score_page` 已有 `if mode != "quick"` 分支
  自动处理，K 轮精炼只影响 deep/thesis/list 模式
